# Mint & Lily Creator Engine

AI-powered influencer program built with Next.js, Supabase, and Claude.

## Setup

1. Run the SQL in `lib/schema.sql` in your Supabase SQL editor
2. Copy `.env.example` to `.env.local` and fill in your keys
3. Add the same env vars to Vercel

## Deploy

Push to GitHub → connect to Vercel → add env vars → deploy.
